# Deepu Mehra — Portfolio

An accessible, responsive portfolio built with plain HTML, CSS and JavaScript. The visual environment combines CSS 3D geometry, pointer parallax and a lightweight canvas particle field. The content remains usable when canvas or motion is unavailable.

## Run locally

```sh
npm run dev
```

Then open `http://127.0.0.1:4173`.

## Build

```sh
npm run build
```

The static production site is written to `dist/`.
